## 📋 版本概述

v1.0.0 是 WinDnsSyncAgent 的首个正式版本，完成了面向 Windows DNS 的双端 Agent 同步闭环：标准 Go Agent、Windows Server 2008/2008 R2 Legacy Agent、手动同步命令、mirror/addOnly 同步模式、dryRun 预览、API Key 认证、A/AAAA 改写、子级域目录同步、委派 NS 同步以及 Windows 发布包构建流程。

---

## ✨ 新增特性

- 新增 `agent` 运行模式，在 DNS 服务器上提供 HTTP API 查询和写入 DNS Zone/Record。
- 新增 `sync` 运行模式，支持从源 Agent 拉取记录并更新到目标 Agent。
- 新增 Windows Server 2012+ 标准 Go Agent，基于 `DnsServer` PowerShell 模块读写 DNS。
- 新增 Windows Server 2008/2008 R2 Legacy Agent，基于 WMI 读取 Zone，并通过 `dnscmd.exe` 读写记录。
- 新增 `mirror` 和 `addOnly` 两种同步模式。
- 新增 `dryRun` 预览模式，可在不写入目标 DNS 的情况下查看同步计划。
- 新增 `includeZones` 与 `excludeZones` 配置，支持按 Zone 或 Zone 下子级域目录选择同步范围。
- 新增旧配置字段 `zones` 到 `includeZones` 的兼容映射。
- 新增 A/AAAA 记录同步后改写能力，支持按 `oldIp` 精确改写到目标 IP。
- 新增 A 记录创建关联 PTR 的 best-effort 能力。
- 新增 API Key 认证配置，支持源端和目标端分别设置密钥。
- 新增子级域目录记录同步能力，支持 `test.cursor.com` 这类节点目录范围。
- 新增 DNS 委派记录同步能力，非根节点 `NS` 记录会作为委派参与同步。
- 新增 Go Agent 删除记录后的空 DNS 节点 best-effort 清理能力。
- 新增 `agent.ps1`、`agent.cmd`、`sync.ps1`、`sync.cmd` 入口脚本，兼容老版本 PowerShell。
- 新增 GitHub Actions 标签发布工作流，支持 Windows AMD64 发布包和校验文件。

## 🐛 Bug 修复

- 修复 Windows Server 2008/2008 R2 Legacy Agent 读取子级域目录时遗漏纯目录节点记录的问题。
- 修复 Legacy Agent 读取委派节点时遗漏单标签委派 `NS` 记录的问题。
- 修复 Legacy Agent 写入委派 `NS` 时缺少 `dnscmd.exe /RecordAdd` 和 `/RecordDelete` 参数分支的问题。
- 修复 Legacy Agent 生成 `dnscmd.exe` 写入参数时空 `WriteName` 被误当作有效节点名，导致 `RecordDelete` 参数不完整的问题。
- 修复同名多 IP 记录比较和同步时只按名称判断导致漏新增或误更新的问题。
- 修复 `@` 与“与父文件夹相同”记录在 Go Agent 和 Legacy Agent 中名称归一不一致的问题。
- 修复 Go Agent 写入完整 FQDN 或子级目录记录时可能误建到根节点或校验失败的问题。

## 🚀 性能优化

- 新增批量记录写入接口 `/dns/zones/{zone}/records/batch`，每个 Zone 同步时只启动一次目标端 PowerShell。
- Go Agent 执行 PowerShell 时写入临时 `.ps1` 文件后通过 `-File` 运行，避免大量记录触发 Windows 命令行长度限制。
- 支持 `zoneConcurrency` 控制 Zone 级并发同步，默认并发数为 2。
- Legacy Agent 使用 `dnscmd.exe /ZonePrint` 发现需要补扫的子节点，减少对不相关节点的重复枚举。

## 🔧 重构优化

- 建立 Go 后端分层结构，划分 `agent`、`config`、`dns`、`syncer` 模块。
- 统一 DNS 记录模型和批量写入模型，使用 `zone + type + name + value` 作为记录身份判断基础。
- 统一根节点、空名称、`.` 和 `@` 的记录名归一逻辑。
- 将 `includeZones`、`excludeZones` 解析为 Zone 选择项，支持按子树过滤源端和目标端记录。
- 将受保护记录规则收敛为 `SOA` 和 Zone 根节点 `NS`，允许非根节点 `NS` 委派参与同步。

## 🔄 API 变更

首个正式版本提供以下 API：

- `GET /health`：服务健康检查。
- `GET /dns/zones`：获取 DNS Zone 列表。
- `POST /dns/zones`：创建 Primary Zone。
- `DELETE /dns/zones/{zone}`：删除指定 Zone。
- `GET /dns/zones/{zone}/records`：获取指定 Zone 的解析记录。
- `POST /dns/zones/{zone}/records`：新增解析记录。
- `DELETE /dns/zones/{zone}/records/{type}/{name}?value={value}`：删除精确匹配的解析记录。
- `POST /dns/zones/{zone}/records/batch`：批量新增、删除、更新解析记录。

支持记录类型：`A`、`AAAA`、`CNAME`、`MX`、`TXT`、`PTR`、`NS`、`SRV`。同步逻辑保护 `SOA` 和 Zone 根节点 `NS`，非根节点 `NS` 作为 DNS 委派参与同步。

## 🔄 升级说明

v1.0.0 为首个正式版本，无历史版本升级迁移要求。

全新部署时请在源 DNS 和目标 DNS 服务器上准备 `config/agent.json`，在同步执行机上准备 `config/sync.json`。Windows Server 2008/2008 R2 请使用 Legacy Agent，并确保系统具备 DNS 管理工具、`dnscmd.exe`、WMI `root\MicrosoftDNS` 权限；目标端 2008/2008 R2 如需接收批量写入请求，还需要可用的 `.NET System.Web.Extensions` JSON 解析组件。

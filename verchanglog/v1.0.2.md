# WinDnsSyncAgent v1.0.2 版本更新日志

**发布日期**: 2026-06-12<br>
**提交数量**: 2 次提交<br>
**版本类型**: Go Agent 记录接口兼容修复版本

---

## 📋 版本概述

v1.0.2 聚焦 Go Agent 记录接口的路径兼容性与安全性，新增 body 版记录查询和批量写入接口，避免 Zone 名称直接出现在 HTTP URL 路径中，规避部分环境对域名式路径的拦截、重写或误判。同时同步端保留对旧路径接口的自动回退能力，确保 Windows Server 2008/2008 R2 Legacy Agent 和旧版 Go Agent 可继续兼容。

---

## ✨ 新增特性

- Go Agent 新增 `POST /dns/records/query` 接口，通过 JSON body 的 `zone` 字段查询指定 Zone 解析记录。
- Go Agent 新增 `POST /dns/records/batch` 接口，通过 JSON body 的 `zone` 字段和 `batch` 字段批量新增、删除、更新解析记录。
- 同步端优先调用 body 版记录接口，目标端返回 `404` 时自动回退到旧版路径接口。

---

## 🐛 Bug 修复

- 修复部分网络设备、代理或安全策略可能拦截 `/dns/zones/{zone}/records` 这类包含域名路径的请求，导致 Go Agent 记录查询或批量写入失败的问题。
- 修复同步端无法区分新接口 `404` 与其他 HTTP 错误的问题，现在仅在 `404` 时回退旧接口，其他错误会正常返回。

---

## 🚀 性能优化

本版本未调整同步算法和批量写入性能。新增 body 版接口主要用于提升路径兼容性和请求稳定性。

---

## 🔧 重构优化

- 同步端新增 HTTP 状态错误类型，便于按状态码判断是否需要回退旧接口。
- 为 body 版记录查询和批量写入接口补充单元测试，验证 Zone 名称可从请求体读取。

## 🔄 API 变更

本版本新增 Go Agent body 版记录接口：

- `POST /dns/records/query`：获取指定 Zone 的解析记录，请求体示例为 `{"zone":"example.com"}`。
- `POST /dns/records/batch`：批量新增、删除、更新解析记录，请求体示例为 `{"zone":"example.com","batch":{"add":[],"delete":[],"update":[]}}`。

兼容性说明：

- Windows Server 2008/2008 R2 Legacy Agent 不支持上述 body 版接口。
- 同步程序会优先调用 body 版接口；若返回 `404`，会自动回退到 `GET /dns/zones/{zone}/records` 或 `POST /dns/zones/{zone}/records/batch`。
- 旧版路径接口继续保留，现有部署无需立即调整调用方式。

---

## 📊 数据库变更

本项目不使用数据库，v1.0.2 无数据库 schema 变更。

---

## 🔄 升级说明

从 v1.0.1 升级到 v1.0.2 时，建议同步更新源端和目标端 Go Agent 可执行文件，并更新同步执行机上的同步程序可执行文件。

如果环境中仅使用 Windows Server 2008/2008 R2 Legacy Agent，旧接口仍保持兼容；若同步端已升级到 v1.0.2，连接 Legacy Agent 时会自动回退旧路径接口，无需额外配置。
